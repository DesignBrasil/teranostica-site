# Sistemática Teranóstico · site público

Síntese navegável do projeto **Plataforma Teranóstica** (Hospital Israelita Albert Einstein · Health Design Lab): o ciclo
teranóstico em seis abas que cabem numa tela — a abertura (o átomo teranóstico: ver, tratar, reavaliar), as quatro
camadas (quem regula, paga e fornece · os sistemas que já existem · as cinco terapias · o que o paciente atravessa) e a
direção: a decisão da Fase 3.

Publicado pelo GitHub Pages em **https://designbrasil.github.io/teranostica-site/**.

| Caminho | O que é |
|---|---|
| `/` | a peça, em seis abas: 0 ABERTURA · 1 ECOSSISTEMA · 2 SISTEMA · 3 SERVIÇOS · 4 JORNADAS · 5 DIREÇÃO. O estado fica na URL (`?vista=…&item=…`) |

Este repositório contém **só o que o site serve** (`.html`, `.css`, `.js`, `.svg`). Os dados, as entrevistas, as notas e
os registros do projeto ficam no vault privado `DesignBrasil/teranostica-platform`; os arquivos daqui são **gerados** a
partir dele por `08_sintese/dados/publica_tudo.py`, que roda um detector de vazamento antes de copiar e cria uma tag
`pub-NNN` por publicação (o rodapé traz "Estado em DD/MM/AAAA · publicação N"). Não editar os arquivos publicados à mão:
a próxima publicação os sobrescreve. O único arquivo editado aqui diretamente é este README.

Na tela vão papéis, nunca nomes de pessoas. Sem valores em reais, sem nomes de operadoras ou fornecedores privados.

Molde: a Sistemática da Longevidade (`DesignBrasil/centro-longevidade-einstein-site`) e a do Health Data Brasil
(`BiodesignBrasil/hdb-site`).
